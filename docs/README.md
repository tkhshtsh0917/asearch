`docs/`はMarkdownの説明と仕様を置く場所です。実行コードは`crates/`・`packages/`・`tools/`、改変しない上流資料は`vendor/`に配置します。上流のコードはテストの入力であり、製品の実装ではありません。完了済み作業の引き継ぎ手順や、設計時の代理計測ログは現行ドキュメントとして維持しません。
