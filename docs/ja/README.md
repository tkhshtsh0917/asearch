[ルートREADME](../../README.ja.md)は準備・CLIコマンド・リリースを説明します。Rust APIの詳細は`cargo doc --workspace --no-deps`で参照できます。JS/TSバインディング、ブラウザ連携とその契約は[asearch-demo/integration](https://github.com/tkhshtsh0917/asearch-demo/tree/main/integration)で管理します。

SVGの図は拡大しても鮮明です。GIFの解説には静止画PNGとテキストによる代替説明もあります。両言語は同じバイト配置と数値例を使います。

[性能改善の採否](performance.md)は採用した最適化、不採用案、再現可能な比較を説明します。変遷および変更前後のGIFは、採用した各最適化の処理の変更・理由・観測効果を示します。

[ネイティブの日本語解析](analysis.md)はサーバー専用のSudachi、言語リソースの変換、ローマ字読み、設定可能な上限を説明します。

[検索結果の順位](ranking.md)は既定順序と任意の一致位置順序を定義し、別名の選択、資源コスト、セグメントの統合も説明します。
